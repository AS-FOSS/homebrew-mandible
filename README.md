# homebrew-mandible

Homebrew tap for [mandible](https://github.com/AS-FOSS/mandible), the
universal, interactive TUI reference for CLI tools.

```console
$ brew install as-foss/mandible/mandible
```

Or tap once and install by name:

```console
$ brew tap as-foss/mandible
$ brew install mandible
```

The formula installs a prebuilt binary for macOS and Linux (Apple Silicon,
Intel, aarch64, x86_64), the man page, and shell completions. It is updated
automatically when mandible publishes a release; issues belong on the
[main repository](https://github.com/AS-FOSS/mandible/issues).
